## Overview

**Taply** is a live digital business card platform that enables instant, zero-install QR-based contact sharing. Any QR code ever shared **auto-updates in real time** when the user's profile changes — completely eliminating stale paper cards.

## Key Features

### **Zero-Install QR Sharing**
- Any recipient can scan and view the card without installing an app
- QR codes auto-update in real time when profile changes via Supabase Realtime

### **Authentication**
- End-to-end Supabase Auth with Email, Google OAuth, and GitHub OAuth
- Row Level Security for secure, per-user data isolation

### **Profile & Links**
- Interactive draggable Links Manager for ordering social/contact links
- Avatar upload with client-side compression
- 3-screen first-time onboarding flow

### **Analytics Dashboard**
- Real-time total scan counts, device breakdown (mobile vs. desktop)
- Recent scan history with timestamps

### **Sharing & Themes**
- Card sharing via clipboard, save-to-device, and native iOS/Android share sheets
- 4 global color themes: Minimal, Lavender, Sage, Ocean
