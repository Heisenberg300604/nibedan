## Overview

**Travello** is a gamified tourism platform built during a 48-hour hackathon to solve the problem of disengaged travel experiences. It transforms destination exploration into an interactive adventure using AI and game mechanics.

## Key Features

### **AI-Powered Personalization**
- Dynamic itinerary generator adapting to user preferences, real-time events, and weather
- AI chat for destination recommendations and trip planning

### **Gamification**
- Points, badges, and achievements for completing challenges
- Photo challenges requiring angle-matched shots at specific attractions
- Leaderboards and competitive quests between travelers

### **Eco-Travel System**
- Green Points for eco-friendly travel choices (walking, public transport)
- Carbon footprint tracker with alternative suggestions
- Local reward redemption for sustainable behavior

### **Interactive Map**
- Mapbox integration for geospatial exploration
- Hidden attraction markers unlocked by completing quests
- Live event overlays
